# Withdrawal Table — TOTO12

Aplikasi satu halaman (HTML/CSS/JS) untuk mengelola data withdrawal e-wallet.

## Fitur
- **Parse data** tempelan dari sistem (dua format didukung) langsung ke tabel.
- **Filter jenis e-wallet**: DANA, GOPAY, LINKAJA, OVO, SHOPEEPAY — dengan jumlah per jenis.
- **Pewarnaan** baris & panel sesuai jenis e-wallet.
- **Copy** per kolom, dan copy No.Rek per baris (klik baris).
- **Sortir** berdasarkan tanggal/jam.
- Statistik: total data & total nominal (mengikuti filter aktif).
- Kapasitas hingga 5000 data.

## Menjalankan
Buka `index.html` di browser, atau taruh di folder web server (mis. XAMPP `htdocs`) lalu akses lewat `localhost`.

## Struktur
- `index.html` — seluruh aplikasi (markup, style, script).
- `assets/toto12.gif` — logo brand.
